1. facts_grounded: каждый факт, цифра и цитата в тексте есть в карточке героя (не придуманы, не искажены).
2. hook_standalone: хук понятен без контекста, без названия компании, останавливает скролл.
3. unique_insight: инсайт проходит тест на уникальность (не подходит к 100 другим компаниям).
4. lesson_and_question: есть урок для читателя и финальный вопрос, провоцирующий развёрнутый ответ (не «да/нет»).
5. no_irony_at_hero: ирония только над ситуацией, рынком или собой; без юмора на темы потерь и кризисов героя.
6. confidentiality: нет непубличных деталей сделок, цен, участников; активы клиентов обезличены; приватные данные созвона не использованы без согласия.
7. no_hidden_sale: в посте нет оффера, только польза и открытая дверь.
8. voice: живой разговорный язык, первое лицо, без канцелярита и машинных оборотов, есть одна честная оговорка.
