# Content Agent — посты-анализы о люксовых отельных активах

Конвейер из пяти агентов и одного человека по инструкции «Автоматизация постов-анализов».
Машина ищет, исследует, анализирует и пишет черновик. Человек одобряет, публикует и ведёт диалог.

```
Разведчик → Исследователь → Аналитик → Автор → Редактор → Решение человека → Публикация → Обучение
               ↑ банальный инсайт ┘          ↑ ошибка ┘                                  │
Разведчик ← лучшие приёмы в промпт и отбор ←─────────────────────────────────────────────┘
```

| Агент | Вход | Выход | Код |
|---|---|---|---|
| Разведчик | профиль, темы, стоп-лист | кандидаты со скорингом от 20/30 | `agents.scout` |
| Исследователь | кандидат | карточка героя: факты и цитаты со ссылками | `agents.research` |
| Аналитик | карточка | линза, инсайт, урок; тест на уникальность | `agents.analyze` |
| Автор | готовая карточка | 2 варианта поста (или `NEED_MORE_DATA`) | `agents.write` |
| Редактор | черновики | автопроверки + смысловые проверки, возврат автору | `checks.py`, `agents.edit` |
| Человек | проверенные посты | выбор A/B, правка, своя деталь, публикация | `review` |

## Установка

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
```

Модель по умолчанию `claude-opus-5-5`, сменить можно через `--model` или `CONTENT_AGENT_MODEL`. Поиск
идёт через встроенные в Claude инструменты web search и web fetch. Если классификатор безопасности
отклонит запрос, сервер автоматически повторит его на другой модели (`fallbacks: "default"`).
Отключить: `CONTENT_AGENT_FALLBACKS=0`.

## Настройка (один раз, обновлять раз в квартал)

`config/profile.yaml`: имя автора, сегменты и баланс 35/35/30, темы, ключевые слова, источники,
линзы ниши, примеры хуков, стоп-лист, правила (порог скоринга, пауза героя 90 дней, лимиты возвратов).

Заметки с созвонов кладите в `data/call_notes/<имя-героя>.md`. Они помечаются как приватные
и не попадут в пост без согласия героя (`"hero_consent": true` в `card` файла `data/posts/<id>/post.json`).

## Рабочий цикл

```bash
# 3–4 раза в неделю: весь конвейер, готовит N постов в очередь
python -m content_agent run --posts 3            # --focus "branded residences на Ближнем Востоке"

# или по шагам
python -m content_agent scout -n 8
python -m content_agent process 0 2              # номера кандидатов из scout

python -m content_agent list                     # очередь, статусы, баланс сегментов за месяц
python -m content_agent review <id>              # 5–10 минут: A/B, правка в $EDITOR, чек-лист, одобрение
# публикуете вручную (ссылки — в первый комментарий), в первый час отвечаете на комментарии
python -m content_agent published <id> --url <ссылка>
python -m content_agent metrics <id>             # через 48 часов
python -m content_agent learn                    # раз в неделю: образцы → промпт автора, выводы → разведчику
```

Состояние хранится в `data/` (в git не попадает): кандидаты, посты (`post.json` + `final.md`),
выученные приёмы (`learned.md`, `scout_adjustments.md`).

## Что гарантирует система

- Каждый факт в карточке со ссылкой. Ссылки сверяются с реальными результатами поиска,
  в посте можно использовать только источники из карточки.
- Инсайт проходит тест на уникальность. Если нет, исследование повторяется (до 2 раз), потом герой отклоняется.
- Код редактора проверяет: 600–1800 знаков; абзацы не длиннее 3 строк; стоп-лист и запрещённые
  начала; не больше одного «!» и 3 эмодзи; герой отмечен, отметок не больше 3; 3–5 хэштегов;
  нет ссылок в тексте; цифра в первых двух строках.
- Модель проверяет смысл: факты не искажены, хук понятен без контекста, есть урок и вопрос,
  нет иронии над героем, нет нарушения конфиденциальности и скрытой продажи, живой голос.
- Ни один пост не публикуется без человека. Автопостинга и парсинга LinkedIn нет: так требуют правила площадки.
